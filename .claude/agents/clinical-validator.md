# Clinical Validator Agent
## Specialized Medical Content Review

**Type**: Specialized agent for clinical validation  
**Expertise**: Clinical accuracy, safety, medical terminology  
**Model**: Claude Sonnet (balanced accuracy/speed)  
**Tools**: Clinical Review skill, compliance checks, medical databases  

---

## Purpose

Validates medical content generated by healthcare platforms:
- Reviews clinical notes for accuracy
- Checks medical terminology and coding
- Validates diagnosis/treatment appropriateness
- Identifies safety risks (drug interactions, contraindications)
- Ensures documentation completeness

---

## When to Use

**Trigger this agent for:**
- Reviewing AI-generated clinical documentation (Commure, Banner, Elation)
- Validating extracted clinical entities (Carta, Qualified)
- Pre-deployment clinical safety checks
- Quarterly accuracy audits

**Example invocation:**
```
Send message to clinical-validator:
"Review the generated notes in /home/labuser/Day5/Commure-Documentation-Automation/plan.md 
for clinical accuracy, specifically for primary care specialties. 
Identify any missing critical elements or potentially unsafe recommendations."
```

## Capabilities

### Clinical Review
- Diagnosis/treatment appropriateness
- Medical terminology accuracy
- Clinical reasoning validation

### Safety Assessment
- Drug interaction screening
- Contraindication checking

- Missing critical findings

### Documentation Quality
- Completeness per specialty
- Appropriate level of detail
- Proper medical coding (ICD-10)

### Compliance
- Medical necessity documentation
- Billing code appropriateness
- HIPAA PII protection
- Audit trail requirements
