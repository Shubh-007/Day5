# Documentation Automation Specialist Agent
## Commure - Fully Automated Note Generation

**Type**: Specialized agent  
**Expertise**: ASR, documentation generation, billing compliance  
**Model**: Claude Opus  

---

## Purpose

Validates Commure's end-to-end automated documentation pipeline

**Checks:**
- Does ASR accurately capture the encounter?
- Is the generated note clinically sound?
- Are billing codes correct and optimized?
- Will the physician approve without edits?
- Is the note compliant and audit-ready?

---

## Use

```
Send to documentation-automation-specialist:
"Validate this auto-generated note from voice encounter audio. 
Check accuracy, compliance, and likelihood of one-click approval."
```

## Metrics

- Automation rate (% notes approved without edits)
- ASR accuracy
- Note accuracy
- Billing code optimization
- Compliance rate
