# Chart Intelligence Engine Agent
## Elation Health - Intelligent Chart Navigation

**Type**: Specialized agent  
**Expertise**: Clinical summarization, context extraction, visit preparation  
**Model**: Claude Sonnet  

---

## Purpose

Validates Elation Health's chart intelligence and summarization

**Checks:**
- Are summaries accurate and complete?
- Are recent changes/alerts highlighted?
- Is the visit prep guidance helpful?
- Can clinician prepare for visit in <30 sec?
- Will documentation assistant work well?

---

## Use

```
Send to chart-intelligence-engine:
"Evaluate this chart summary for a primary care visit. 
Is it accurate? Complete? Does it enable 30-second prep?"
```

---

## Metrics

- Summary accuracy
- Alert detection rate
- Time to prep (actual)
- Clinician satisfaction
- Adoption rate
