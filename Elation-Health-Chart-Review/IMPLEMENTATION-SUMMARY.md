## Feature Overview

### 🤖 RAG Chatbot Capabilities

#### Query Types Supported (7):

1. **💊 Drug Interactions**
   - Detects medications in patient record
   - Checks for dangerous combinations
   - Shows severity levels and management tips
   - Example: "What drug interactions should I check?"

2. **🧪 Lab Values**
   - Identifies abnormal labs
   - Shows normal ranges
   - Indicates trends
   - Example: "Are there any abnormal labs?"

3. **📚 Clinical Guidelines**
   - Retrieves condition-specific guidelines
   - Management recommendations
   - Evidence-based protocols
   - Example: "What are the guidelines for hypertension?"

4. **🚨 Safety & Allergies**
   - Lists known allergies
   - Shows severity levels
   - Highlights contraindications
   - Example: "What allergies does this patient have?"

5. **🏥 Preventive Care**
   - Identifies overdue screenings
   - Age/gender-appropriate recommendations
   - Screening frequencies
   - Example: "What preventive care is due?"

6. **📊 Vital Signs**
   - Current vital measurements
   - Contextual interpretation
   - Trend indicators
   - Example: "What are the vital signs?"

7. **🔬 General Knowledge**
   - Falls back to RAG search
   - Broad clinical knowledge
   - Evidence-based information
   - Example: "What is [condition]?"

## Technical Architecture

### Data Flow

```
┌─────────────────────────────────────────┐
│  Frontend (React + RAGChatbot.jsx)      │
│  - User types question                  │
│  - Displays in collapsible chat UI      │
│  - Shows sources & confidence           │
└──────────────────┬──────────────────────┘
                   │ POST /api/tools/chat/rag
                   ↓
┌──────────────────────────────────────────┐
│  Backend (FastAPI + tools_api.py)       │
│  - rag_chatbot() endpoint                │
│  - Intent detection (keyword matching)   │
│  - Query routing                         │
└──────────────────┬──────────────────────┘
                   │
                   ↓
┌──────────────────────────────────────────┐
│  RAG Engine (rag_engine.py)              │
│  - Clinical Knowledge Base               │
│  - Data retrieval                        │
│  - Drug interactions                     │
│  - Guidelines & screening                │
└──────────────────┬──────────────────────┘
                   │
                   ↓
┌──────────────────────────────────────────┐
│  Response Formatters                     │
│  - format_drug_interaction_response()    │
│  - format_lab_response()                 │
│  - format_guidelines_response()          │
│  - format_safety_response()              │
│  - format_preventive_care_response()     │
│  - format_vitals_response()              │
│  - format_general_response()             │
└──────────────────┬──────────────────────┘
                   │
                   ↓ JSON + sources + confidence
┌──────────────────────────────────────────┐
│  Frontend Display                        │
│  - Show response with formatting         │
```
